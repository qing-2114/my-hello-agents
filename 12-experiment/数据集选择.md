## 不依赖 Hugging Face 账号的候选

| 数据集 | 适合评估 | 作者提供的获取方式 | 主要限制 |
| --- | --- | --- | --- |
| HotpotQA | 多跳检索、证据定位、回答 | 作者仓库提供 JSON 下载链接 | 主要是文本与维基百科，不覆盖 GAIA 的多模态工具任务 |
| MuSiQue | 组合式多跳推理、检索链 | 作者仓库提供 Google Drive 下载与脚本 | 需能访问 Google Drive；不是通用工具执行环境 |
| BIG-Bench Hard（BBH） | 多步推理，23 类任务 | GitHub 的 `bbh/` JSON 文件 | 主要评估模型推理，不能单独代表 Agent 能力 |
| GSM8K | 数学多步推理、计算器工具增益 | GitHub 的 `grade_school_math/data/test.jsonl` | 能力面较窄，现代模型可能接近饱和 |
| GPQA | 研究生级科学知识与推理 | 作者 GitHub 的 `dataset.zip`，解压口令见 README | 难度高、领域偏科学，不能替代工具使用评测 |

官方来源：

- HotpotQA：<https://github.com/hotpotqa/hotpot>
- MuSiQue：<https://github.com/StonyBrookNLP/musique>
- BBH：<https://github.com/suzgunmirac/BIG-Bench-Hard>
- GSM8K：<https://github.com/openai/grade-school-math>
- GPQA：<https://github.com/idavidrein/gpqa>

## 本章建议

先保留 BFCL 的工具调用评估，用 HotpotQA 的开发集做多跳检索评估，再选 BBH 的部分任务补充推理评估。首次每类取 20–50 题验证流程，固定样本 ID 与随机种子，记录正确率、检索证据、工具调用次数、耗时和 token 用量。GAIA 权限恢复后再补充其评测。

小样本结果用于工程调试，不能直接视为完整基准成绩；上述组合覆盖不同能力，不等同于 GAIA 分数。
